# Документация для пользователей Architect RED 2

Добро пожаловать в документацию по фреймворку Architect RED 2! Этот раздел предназначен для разработчиков, которые хотят быстро начать работу с фреймворком, изучить его возможности и лучшие практики.

## Что такое Architect RED 2?

Architect RED 2 — это современный PHP-фреймворк для создания веб-приложений любой сложности. Он сочетает в себе простоту использования, мощную модульную архитектуру и высокую производительность.

**Ключевые преимущества:**
- **Statement-based MVC** — чёткий жизненный цикл приложения.
- **Контейнер зависимостей** — лёгкое управление сервисами.
- **Несколько приложений в одном проекте** — разделение функционала.
- **Гибкая конфигурация через JSON** — настройка под любое окружение.
- **Мощный шаблонизатор Blueprint** — похожий на Blade/Twig.
- **ORM Axiom** — удобная работа с базами данных.
- **Встроенная отладочная панель** — мониторинг производительности.
- **Система аутентификации** — готовая RBAC-система.
