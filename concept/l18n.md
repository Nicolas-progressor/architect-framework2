
## Концепция мультиязычного модуля I18n для Architect Blueprint


### Название модуля
**Blueprint I18n Module** — модуль интернационализации (I18n) для шаблонизатора Blueprint с поддержкой множества языков и гибкой системой переводов.

### Цели модуля
* обеспечение мультиязычной поддержки шаблонов Blueprint (.blu);
* простая интеграция переводов в шаблоны;
* поддержка сложных грамматических конструкций (склонение, множественное число);
* высокая производительность за счёт кэширования;
* удобство для разработчиков и переводчиков.

### Ключевые возможности
* поддержка произвольного количества языков;
* автоматическая подстановка переводов в шаблонах;
* работа с множественным числом и грамматическими формами;
* контекстные переводы (одно слово может иметь разные значения);
* fallback‑языки (резервный язык при отсутствии перевода);
* интеграция с существующими системами переводов.

---

## Архитектура модуля

### Компоненты
1. **Translator** — основной класс для работы с переводами.
2. **Loader** — загрузчик файлов переводов (JSON, PO, YAML).
3. **Cache** — кэширование скомпилированных переводов.
4. **Extractor** — инструмент для извлечения строк из шаблонов.
5. **Formatter** — форматирование сообщений с параметрами.
6. **Pluralizer** — обработка множественного числа для разных языков.

### Поддерживаемые форматы файлов переводов
* **JSON** — простой и удобный формат:
```json
{
  "welcome_message": "Добро пожаловать!",
  "items_count": "{0} Нет товаров|{1} {count} товар|{2,4} {count} товара|{5,} {count} товаров"
}
```
* **PO/MO** — стандарт для GNU gettext.
* **YAML** — структурированный формат для сложных переводов.
* **PHP arrays** — нативный формат PHP.

## API для разработчиков

### Инициализация модуля
```php
use Blueprint\I18n\I18nModule;

$i18n = new I18nModule([
    'default_locale' => 'ru',
    'fallback_locale' => 'en',
    'translations_dir' => '/path/to/translations',
    'cache_dir' => '/path/to/cache',
    'debug' => true
]);

$blueprint->registerModule($i18n);
```

### Настройка языков
```php
$i18n->addLocale('ru', 'Русский');
$i18n->addLocale('en', 'English');
$i18n->addLocale('es', 'Español');

// Установка текущего языка
$i18n->setLocale('es');
```

## Синтаксис в шаблонах (.blu)

### Базовые переводы
```twig
<h1>{{ trans('welcome_message') }}</h1>
<p>{{ trans('footer.copyright', {'year': current_year}) }}</p>
```

### Множественное число
```twig
<p>{{ plural('items_count', items|length, {'count': items|length}) }}</p>
<!-- Выведет: "3 товара" или "15 товаров" -->
```

### Контекстные переводы
```twig
<!-- «file» в контексте документа -->
<span>{{ trans_context('file', 'document', {'name': filename}) }}</span>

<span>{{ trans_context('file', 'computer', {'name': filename}) }}</span>
```

### Сложные параметры
```twig
<p>
    {{ trans('user_joined', {
        'name': user.name,
        'date': user.join_date|format_date
    }) }}
</p>
```

### Проверка доступности перевода
```twig
{% if has_translation('premium_feature') %}
    <div class="premium">{{ trans('premium_feature') }}</div>
{% endif %}
```

## Система множественного числа

Модуль поддерживает сложные правила множественного числа для разных языков:

**Конфигурация правил:**
```php
$pluralRules = [
    'ru' => function ($n) {
        return ($n % 10 == 1 && $n % 100 != 11) ? 0 :
               ($n % 10 >= 2 && $n % 10 <= 4 && ($n % 100 < 10 || $n % 100 >= 20) ? 1 : 2;
    },
    'en' => function ($n) { return $n == 1 ? 0 : 1; },
    'fr' => function ($n) { return ($n > 1) ? 1 : 0; }
];
```

**Использование в шаблонах:**
```twig
<!-- В шаблоне -->
<p>{{ plural('comments_count', comment_count, {'count': comment_count}) }}</p>

<!-- В JSON -->
"comments_count": "{0} Нет комментариев|{1} {count} комментарий|{2,4} {count} комментария|{5,} {count} комментариев"
```

## Инструменты для переводчиков

### Экстрактор строк
Автоматическое извлечение строк для перевода из шаблонов:
```bash
php vendor/bin/blueprint-i18n extract templates/ -o translations/
```
Создаёт файлы:
* `messages.pot` — шаблон для переводчиков;
* `ru.json`, `es.json` — файлы переводов.

### Менеджер переводов
Веб‑интерфейс для управления переводами:
* просмотр всех строк для перевода;
* поиск и фильтрация;
* отслеживание статуса перевода;
* комментарии для переводчиков.

### Валидатор переводов
Проверка целостности файлов переводов:
```bash
php vendor/bin/blueprint-i18n validate translations/ru.json
```
Проверяет:
* корректность синтаксиса JSON/YAML;
* наличие всех требуемых ключей;
* соответствие параметров в шаблонах.

## Кэширование и производительность

### Стратегии кэширования
1. **Файл‑кэш** — скомпилированные переводы в PHP‑файлах.
2. **APCu/Redis** — высокопроизводительное кэширование.
3. **Ленивая загрузка** — загрузка только используемых переводов.

**Настройка:**
```php
$i18n->setCacheAdapter(new FileCache('/path/to/cache'));
// или
$i18n->setCacheAdapter(new RedisCache($redisClient));
```

### Оптимизация
* прекомпиляция переводов при деплое;
* автоматическое обновление кэша при изменении файлов;
* пакетная загрузка переводов.

## API для разработчиков

### Программная работа с переводами
```php
// Получение перевода напрямую
$translation = $i18n->translate('welcome_message');

// С параметрами
$translation = $i18n->translate('user_joined', [
    'name' => 'Иван',
    'date' => '10.05.2023'
]);

// Множественное число
$translation = $i18n->plural('items_count', 5, ['count' => 5]);
```

### Управление языками во время выполнения
```php
// Временная смена языка
$i18n->withLocale('en', function () use ($blueprint) {
    echo $blueprint->render('page.blu');
});

// Переключение для текущего запроса
$i18n->setLocaleForRequest('es');
```

### Хуки и события
Модуль предоставляет события для перехвата:
```php
$i18n->on('translation.missing', function ($event) {
    // Логирование отсутствующих переводов
    error_log("Missing translation: " . $event->getKey());
    
    // Автоматическая генерация ключа для переводчика
    $this->addTranslationToQueue($event->getKey());
});
```

## Производительность и оптимизация

### Стратегии загрузки переводов
1. **Полная загрузка** — все переводы загружаются при инициализации (для небольших проектов).
2. **Ленивая загрузка** — переводы загружаются по требованию (рекомендуется).
3. **Пакетная загрузка** — загрузка переводов по группам (например, только для текущей страницы).

**Настройка:**
```php
$i18n->setLoadingStrategy(new LazyLoadingStrategy());
// или
$i18n->setLoadingStrategy(new GroupLoadingStrategy(['common', 'auth']));
```

### Оптимизация кэширования
```php
// Предварительная компиляция всех переводов
$i18n->precompileTranslations();

// Автоматическое обновление кэша при изменении файлов
$i18n->enableAutoCacheRefresh();
```

## Преимущества модуля I18n

* **Простота интеграции** — минимум кода для мультиязычности.
* **Гибкость** — поддержка разных форматов и структур переводов.
* **Производительность** — оптимизированное кэширование и загрузка.
* **Расширяемость** — возможность добавления кастомных правил и форматов.
* **Удобство для переводчиков** — инструменты экспорта/импорта.
* **Безопасность** — защита от XSS и контроль доступа.

### Расширенные сценарии использования

#### Поддержка RTL‑языков (Right‑to‑Left)
Модуль автоматически определяет направление текста для языков:
* арабский (`ar`);
* иврит (`he`);
* персидский (`fa`) и др.

**Реализация:**
```twig
<div dir="{{ text_direction() }}">
  {{ trans('rtl_example') }}
</div>
```

**В коде PHP:**
```php
if ($i18n->isRTL()) {
    $blueprint->addGlobal('text_direction', 'rtl');
} else {
    $blueprint->addGlobal('text_direction', 'ltr');
}
```

#### Контекстная локализация контента
Динамическое переключение контента в зависимости от языка:
```twig
{% if current_locale() == 'ar' %}
    <div class="arabic-specific-content">...</div>
{% endif %}
```

### Система fallback‑языков

Гибкая цепочка резервных языков:
```php
$i18n->setFallbackChain([
    'es_MX' => ['es', 'en'],  // мексиканский испанский → испанский → английский
    'fr_CA' => ['fr', 'en'],  // канадский французский → французский → английский
    '*' => 'en'               // все остальные → английский
]);
```

### Обработка отсутствующих переводов

**Стратегии:**
1. **Возврат ключа** — показать оригинальный ключ (`welcome_message`).
2. **Fallback‑перевод** — взять из резервного языка.
3. **Автогенерация** — создать запись для переводчика.
4. **Кастомное сообщение** — показать «Перевод отсутствует».

**Настройка:**
```php
$i18n->setMissingTranslationHandler(function ($locale, $key) {
    // Логирование в систему управления переводами
    TranslationManager::queue($key, $locale);
    
    return '[MISSING: ' . $key . ']';
});
```

## API для продвинутой локализации

```php
$i18n->registerPluralRule('sl', function ($n) {
```

## Оптимизация производительности

### Стратегии кэширования

1. **Кэш переводов** — скомпилированные массивы переводов.
2. **Кэш шаблонов** — шаблоны с подставленными переводами.
3. **Кэш правил** — кэширование результатов вычисления множественного числа.

**Конфигурация:**
```php
$config['cache'] = [
    'enabled' => true,
    'adapter' => 'redis',
    'ttl' => 86400, // 24 часа
    'prefix' => 'blueprint_i18n_'
];
```

### Ленивая компиляция переводов

Только используемые переводы компилируются в кэш:
```php
class LazyCompilationStrategy implements CompilationStrategyInterface
{
    public function compile($locale, $keys)
    {
        // Компиляция только запрошенных ключей
        return $this->translator->extractUsedKeys();
    }
}
```

```php
class TranslationDraftGenerator
{
    public function generateDraftsForLocale($targetLocale)
    {
        $sourceLocale = $i18n->getDefaultLocale();
        $keys = $i18n->getAllTranslationKeys($sourceLocale);
        
        $draft = [];
        foreach ($keys as $key) {
            if (!$i18n->hasTranslation($targetLocale, $key)) {

                            $i18n->translate($key, [], $sourceLocale) . ']';
            }
        }
        file_put_contents(
            "translations/{$targetLocale}.json",
            json_encode($draft, JSON_PRETTY_PRINT)
        );
    }
}
```

**Рекомендации для переводчиков:**
* сохранять форматирование оригинальных строк;

### Чек‑лист проверки перед релизом

1. Проверить покрытие переводами (> 95 %).
2. Протестировать RTL‑языки.
3. Проверить форматирование дат/чисел.
4. Убедиться в корректности множественного числа.
5. Протестировать переключение языков на странице.
6. Проверить SEO‑теги hreflang.
7. Запустить тесты производительности.
8. Проверить логи на ошибки переводов.
