# Техническая документация Architect RED 2

Этот раздел содержит подробную техническую документацию по фреймворку Architect RED 2, предназначенную для разработчиков, которые хотят понять внутреннее устройство, расширить функциональность или интегрировать фреймворк в свои проекты.

## Структура документации

1. [Архитектура](architecture.md) — обзор архитектуры, компоненты, жизненный цикл.
2. [Конфигурация](configuration.md) — форматы конфигурационных файлов, переменные окружения.
3. [Ядро](core.md) — Container, Statement, Framework, EnvironmentManager.
4. [Сервисы](services.md) — описание всех сервисов, их API и использование.
5. [Модули и приложения](modules.md) — структура модулей, приложений, маршрутизация.
6. [Шаблонизатор Blueprint](blueprint.md) — синтаксис, функции, интеграция.
7. [ORM Axiom](axiom.md) — конструктор запросов, Entity, JSON ORM.
8. [Система аутентификации](auth.md) — RBAC, middleware, конфигурация.
9. [Отладка и логирование](debug.md) — Debug панель, Logger, Errors.
10. [Расширения](extensions.md) — создание собственных сервисов и модулей.
11. [Миграции и развёртывание](deployment.md) — настройка окружений, миграции БД.
