## 1. Общая характеристика системы

**Architect Framework** — полнотекстовый PHP 8+ фреймворк для построения веб-приложений, включающий ORM, шаблонизатор, систему аутентификации, очередей, валидации, консольный интерфейс и модульную архитектуру (bundles).

**Ключевые решения:**
- PHP 8.1+ (атрибуты, union types, named arguments, enums, fibers)
- PSR-4 автoload (Composer)
- PSR-11 Container (DI)
- PSR-15 HTTP (middleware)
- PSR-18 HTTP Client
- PSR-3 Logger
- Docker-окружение (Nginx + PHP-FPM 8.4 + MySQL 8.0 + Redis 7)
- Мульти-репозиторная структура (8 GitHub репозиториев)

2. **Widgets** — Компонуемые UI-компоненты с `create_app_data()` / `create_app_output()`
3. **App Bootstrap** — Каждое приложение имеет `appbootstrap.php` с lifecycle hooks
4. **Element System** — JSON-определённая композиция страниц (elements.json → page elements)
5. **ORM** — PHP 8 атрибуты (`#[ORM\Column]`, `#[ORM\Entity]`, `#[ORM\Table]`), Query Builder, Entity Manager
6. **Multi-template** — Bootstrap (PHP) и Blueprint (.blu) шаблонизаторы
7. **Middleware** — PSR-15 совместимый middleware pipeline (Auth, CSRF, RateLimit)
8. **Service Providers** — DI регистрация через ServiceProvider паттерн
